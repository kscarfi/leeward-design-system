# @leeward/mcp-server

MCP server that gives AI agents the Leeward design system: tokens, components, rules and a validator for the code they write.

## Tools

| Tool | What it returns |
|---|---|
| `get_tokens(theme?, category?)` | Semantic tokens with CSS variable, value and use. Themes: light, dark. Categories: color, space, radius, size, type, shadow, motion, layer. |
| `get_component(name)` | Import, props with types, variants, do and don't rules, accessibility notes and a correct example. |
| `search_components(query)` | Components ranked for a need, for example "one-time code". |
| `get_guidelines(topic)` | Rules for principles, tokens, color, typography, amounts, forms, errors, layout, copy, accessibility, motion, dark-mode, or all. |
| `validate_ui(code)` | Issues in generated TSX with a fix for each: raw colors, unknown or primitive tokens, raw spacing, unknown components, missing labels, icon-only money actions, red amounts, hand-formatted money, em dashes. |

## Use it with Claude Code in 3 steps

Requires Node.js 24 or newer.

1. Clone and install:

```bash
git clone https://github.com/kscarfi/leeward-design-system.git
```

```bash
cd leeward-design-system && corepack enable pnpm && pnpm install
```

2. Add the server:

```bash
claude mcp add leeward -- node "$PWD/packages/mcp-server/src/index.ts"
```

3. Ask for a screen and tell the agent to use the tools, for example: "Build a money transfer screen with the Leeward design system. Check your code with validate_ui."

Other MCP clients (Cursor and similar) use the same command: `node <repo>/packages/mcp-server/src/index.ts` over stdio.

## Data

The server reads `components.manifest.json` and the compiled tokens from this repo. Both are generated by `pnpm build:agent` and `pnpm build:tokens`, and CI fails if they are stale.
