# PageHeader

The top of a screen: a back button, the title and up to two actions.

## When to use

- Every screen in the app, so titles and back buttons are always in the same place.

## When not to use

- Inside cards or sections: use Heading.

## Anatomy

- Back IconButton (when not a top-level screen).
- Title, rendered as the page's only `h1`.
- Actions on the end side.

## Content guidelines

- The title names the screen in two or three words: "Send money", "Card settings".

## Behavior and responsive

- Long titles truncate with an ellipsis; the back button and actions keep their size.
- `sticky` keeps it at the top while the page scrolls, with a line underneath.

## Do

- Use IconButtons with labels for actions, such as "Help".

## Don't

- Do not put money movement actions here: they belong in the screen's main Button.

## Accessibility

- A `header` containing the `h1`.
- The back button is named "Back" or "Geri".

## Example

```tsx
import { IconButton, PageHeader } from "@leeward/react";

export function SendMoneyHeader() {
  return <PageHeader title="Send money" onBack={() => history.back()} actions={<IconButton icon="help" label="Help" />} />;
}
```
