# Divider

Separates groups of content.

## Do

- Prefer spacing to dividers. Use a divider when two groups would otherwise blur together.

## Don't

- Do not use a divider as the only signal that sections differ.

## Accessibility

- Hidden from screen readers by default. Set decorative={false} when it separates real sections.

## Example

```tsx
<Divider label="or" />
```
