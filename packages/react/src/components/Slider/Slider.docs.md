# Slider

Picks a value in a range when the feel matters more than the exact number, such as a monthly saving amount.

## When to use

- Exploring a range: "How much do you want to save each month?"

## When not to use

- Exact values people already know: use AmountInput or NumberInput.

## Content guidelines

- Format the value for people with `formatValue`, for example with `formatAmount()`.

## Behavior and responsive

- The current value is shown above the track and the limits below it.
- `onValueCommit` fires when people let go, for expensive updates.

## Do

- Pair it with a field when an exact value is also useful.

## Don't

- Do not use a slider for more than a few hundred steps.

## Accessibility

- The thumb has the `slider` role, the label as its name and the formatted value as its value text.
- The track has a 44 px tall hit area.

### Keyboard

| Key | Action |
|---|---|
| Arrow keys | Step by `step` |
| Page up and down | Larger steps |
| Home and End | Jump to the limits |

## Example

```tsx
import { Slider, formatAmount } from "@leeward/react";

export function MonthlySaving() {
  return <Slider label="Save each month" min={0} max={10000} step={250} defaultValue={2000} formatValue={(v) => formatAmount(v, { currency: "TRY", locale: "tr-TR" })} />;
}
```
