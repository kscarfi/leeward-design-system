# DatePicker

One date, typed or picked from a calendar, such as when a scheduled transfer should go out.

## When to use

- A date field in a form: transfer date, date of birth, statement start.

## When not to use

- A date people pick by browsing a month: use Calendar on its own.

## Anatomy

- A text field in the locale's date format and a calendar button that opens Calendar in a popover.

## Content guidelines

- The hint shows the format by default ("DD.MM.YYYY" in Turkish shows as "GG.AA.YYYY").

## Behavior and responsive

- Typed dates are read when the field loses focus: "12.11.2026" in Turkish, "11/12/2026" in English.
- A date that cannot be read, or one outside `min` and `max`, shows a message on the field.
- Choosing a day in the calendar closes it and fills the field.

## Do

- Set `min` and `max`, and disable dates that cannot be used.

## Don't

- Do not make people use the calendar for a date of birth: typing is faster.

## Accessibility

- A normal text field with a visible label and format hint; the calendar button is named "Choose date".
- The calendar follows the WAI-ARIA date grid pattern (see Calendar).

## Example

```tsx
import { DatePicker } from "@leeward/react";

export function TransferDate() {
  const today = new Date();
  return <DatePicker label="Send on" min={today} isDateDisabled={(d) => d.getDay() === 0 || d.getDay() === 6} locale="tr-TR" />;
}
```
