# NumberInput

A whole number with minus and plus buttons, such as a loan term in months or a number of cards.

## When to use

- Small whole numbers with clear limits.

## When not to use

- Money: use AmountInput. Long numbers such as IBANs or card numbers: use TextField.

## Content guidelines

- Put the unit in `unit`, not in the label: label "Loan term", unit "months".

## Behavior and responsive

- Typing is allowed; the value is checked and kept within `min` and `max` when the field loses focus.
- The buttons are disabled at the limits.

## Do

- Set `min` and `max` and say the range in the hint.

## Don't

- Do not use it for numbers people never change step by step.

## Accessibility

- The input has the `spinbutton` role with its value, limits and unit ("12 months").
- The minus and plus buttons are for pointers; keyboard users use the arrow keys, so the buttons are left out of the Tab order.

### Keyboard

| Key | Action |
|---|---|
| Arrow up and down | Step by `step` |
| Page up and down | Step by ten steps |
| Home and End | Jump to `min` and `max` |

## Example

```tsx
import { NumberInput } from "@leeward/react";

export function LoanTerm() {
  return <NumberInput label="Loan term" unit="months" min={3} max={36} step={3} defaultValue={12} hint="Between 3 and 36 months" />;
}
```
