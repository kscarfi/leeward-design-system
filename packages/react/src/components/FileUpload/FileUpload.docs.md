# FileUpload

Adds documents, such as an ID or a proof of address, by drag and drop or with a regular button.

## When to use

- Forms that need a document from the person.

## When not to use

- Profile photos: use the platform's image picker with a preview.

## Anatomy

- Label and hint, a drop zone with a button, a list of chosen files with size and a remove button.

## Content guidelines

- The hint says what is accepted and the limit: "PDF or photo, up to 10 MB".

## Behavior and responsive

- The whole zone opens the file picker; dragging a file over it highlights it.
- Files of the wrong type or over `maxSize` are refused with a message that names the file.

## Do

- Say what happens to the document after upload.

## Don't

- Do not upload automatically before people confirm the form.

## Accessibility

- A native file input, labelled by the visible label; works with keyboard and screen readers.
- Errors are linked to the input; each remove button names its file.

## Example

```tsx
import { FileUpload } from "@leeward/react";

export function ProofOfAddress() {
  return <FileUpload label="Proof of address" hint="PDF or photo, up to 10 MB" accept="application/pdf,image/*" maxSize={10 * 1024 * 1024} />;
}
```
