# Calendar

A month grid for picking one date. DatePicker uses it in a popover; use it on its own when the calendar is the main thing on screen.

## When to use

- Scheduling screens where people see a month, such as standing orders.

## When not to use

- A date field in a form: use DatePicker.

## Anatomy

- Previous and next month buttons and the month name.
- Weekday names, day buttons; today is outlined and the selected day is filled.
- An optional "Today" shortcut.

## Behavior and responsive

- Weeks start on Monday in Turkish and on Sunday in English.
- Dates before `min`, after `max` or rejected by `isDateDisabled` are crossed out and cannot be chosen.

## Do

- Disable dates people cannot use, such as bank holidays for transfers.

## Don't

- Do not use it for date ranges yet.

## Accessibility

- A `grid` named by the month; each day button is named with the full date.
- Today has `aria-current="date"`; the selected day's cell has `aria-selected`.
- The month name is announced when it changes.

### Keyboard

| Key | Action |
|---|---|
| Arrow keys | Move a day or a week |
| Home and End | Start and end of the week |
| Page up and down | Previous and next month |
| Shift with Page up and down | Previous and next year |
| Enter or Space | Chooses the day |

## Example

```tsx
import { useState } from "react";
import { Calendar } from "@leeward/react";

export function StandingOrderDay() {
  const [date, setDate] = useState<Date | null>(null);
  return <Calendar value={date} onValueChange={setDate} min={new Date()} locale="tr-TR" />;
}
```
