# Table

Rows and columns of data people compare, such as a statement on desktop.

## When to use

- Desktop screens where people scan, sort and compare many rows with several values each.

## When not to use

- Phones: use List with TransactionRow.
- Layout: never use a table to place things on a page.

## Anatomy

- Caption, header row, rows. Sortable headers have a sort icon.
- An empty row when there is no data.

## Content guidelines

- The caption says what is listed and for when: "Transactions in November".
- Amounts align to the end and use AmountDisplay.

## Behavior and responsive

- Wide tables scroll sideways inside their frame; the page itself never scrolls sideways.
- Sorting toggles between ascending and descending. Without `onSortChange` the table sorts itself.

## Do

- Add Pagination under long tables.

## Don't

- Do not put more than one action in a row; use a DropdownMenu.

## Accessibility

- A real `table` with a `caption` and `th scope="col"`.
- Sorted columns have `aria-sort`, and the sort button says the direction.
- The scroll frame is focusable and named by the caption, so keyboard users can scroll it.

### Keyboard

| Key | Action |
|---|---|
| Tab | Moves to the scroll frame and to sort buttons |
| Arrow keys | Scroll the frame when it has focus |
| Enter or Space | Sorts by the column |

## Example

```tsx
import { AmountDisplay, Table } from "@leeward/react";

interface Row { id: string; date: Date; merchant: string; amount: number }

const rows: Row[] = [
  { id: "1", date: new Date("2026-11-12"), merchant: "Coffee Lab", amount: -85 },
  { id: "2", date: new Date("2026-11-11"), merchant: "Salary", amount: 52000 },
];

export function Statement() {
  return (
    <Table
      caption="Transactions in November"
      rowKey={(r) => r.id}
      rows={rows}
      defaultSort={{ key: "date", direction: "descending" }}
      columns={[
        { key: "date", header: "Date", sortable: true, render: (r) => r.date.toLocaleDateString("en-US"), sortValue: (r) => r.date },
        { key: "merchant", header: "Merchant", sortable: true },
        { key: "amount", header: "Amount", align: "end", sortable: true, render: (r) => <AmountDisplay value={r.amount} currency="TRY" size="sm" direction={r.amount < 0 ? "outgoing" : "incoming"} /> },
      ]}
    />
  );
}
```
