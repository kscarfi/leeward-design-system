# Banner

A full-width message at the top of the app or a page about something that affects everything there, such as planned maintenance.

## When to use

- System-wide news: maintenance, a service problem, a change in terms.

## When not to use

- A message about one part of the page: use Alert.
- Feedback after an action: use a toast.

## Anatomy

- Tone icon, one or two sentences, an optional action and an optional close button.

## Content guidelines

- Say what is affected and when: "Card payments may fail between 02:00 and 04:00 on Sunday."
- The action names the next step: "See the schedule".

## Behavior and responsive

- Spans the full width; the action wraps under the text on narrow screens.
- Leave out `onDismiss` for problems people cannot fix by closing it.

## Do

- Show one banner at a time.

## Don't

- Do not use banners for marketing.

## Accessibility

- `role="status"` by default; use `live="alert"` only for urgent problems such as an outage.
- The tone is shown by an icon as well as color.

## Example

```tsx
import { Banner, Link } from "@leeward/react";

export function Maintenance() {
  return (
    <Banner tone="warning" action={<Link href="#schedule">See the schedule</Link>} onDismiss={() => {}}>
      Card payments may fail between 02:00 and 04:00 on Sunday.
    </Banner>
  );
}
```
