# Fieldset

Groups related fields under one name, so screen readers announce the group with each field.

## When to use

- Fields that only make sense together: an address, a card's expiry and security code, "pay by IBAN or by phone number".

## When not to use

- A single field: use its own label.
- Checkboxes or radios: CheckboxGroup and RadioGroup already are fieldsets.

## Content guidelines

- The legend is a short noun phrase: "Card address".
- A group error says how the fields relate: "Enter either an IBAN or a phone number".

## Do

- Use `hideLegend` when a heading right above says the same, so screen readers still hear the group name.

## Don't

- Do not nest fieldsets more than one level.

Fieldset uses the spacing scale and the heading xs type role.

## Accessibility

- A `fieldset` with a `legend`; the hint and error are linked with `aria-describedby`.

## Example

```tsx
import { Fieldset, TextField } from "@leeward/react";

export function CardAddress() {
  return (
    <Fieldset legend="Card address" hint="Where we send your new card">
      <TextField label="Street and number" />
      <TextField label="City" />
      <TextField label="Postcode" numeric />
    </Fieldset>
  );
}
```
