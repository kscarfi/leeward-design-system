# Popover

Extra detail next to the thing it explains, such as how a fee is calculated. Unlike Tooltip, it can hold links and buttons.

## When to use

- An explanation people open on purpose, with a title and a few sentences or a link.

## When not to use

- A short hint on hover: use Tooltip.
- A task or a form: use Dialog or Sheet.

## Anatomy

- Title, close button, content and an arrow pointing at the trigger.

## Content guidelines

- The title is a short question or noun: "How is this fee calculated?"
- Keep it under about 40 words.

## Behavior and responsive

- Opens on click or Enter, closes on Escape, a click outside or the close button.
- Repositions to stay on screen.

## Do

- Use a clear trigger, such as an IconButton labelled "About this fee".

## Don't

- Do not hide information people need to decide, such as the fee amount itself.

## Accessibility

- A dialog named by its title; focus moves into it when it opens and back to the trigger when it closes.

### Keyboard

| Key | Action |
|---|---|
| Enter or Space | Opens |
| Tab | Moves through the content |
| Escape | Closes |

## Example

```tsx
import { IconButton, Link, Popover } from "@leeward/react";

export function FeeInfo() {
  return (
    <Popover title="How is this fee calculated?" trigger={<IconButton icon="info" size="sm" label="About this fee" />}>
      <p>Transfers to other banks cost ₺4,50. Transfers between Leeward accounts are free.</p>
      <Link href="#fees">See all fees</Link>
    </Popover>
  );
}
```
