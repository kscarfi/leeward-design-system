# CheckboxGroup

Several independent choices under one question, for example which accounts to include in a statement.

## When to use

- People can pick any number of options, including none.
- A list where "select all" helps, such as notification types or accounts.

## When not to use

- Only one option can be chosen: use RadioGroup.
- A single yes or no: use one Checkbox.
- A setting that applies at once: use Switch.

## Anatomy

- Legend: the question, read as the group's name.
- Optional hint under the legend.
- Optional "select all" checkbox that shows the mixed state when some options are chosen.
- Options, each a Checkbox with its own label and optional hint.
- Group error at the end.

## Content guidelines

- The legend is a short question or noun phrase: "Include these accounts".
- Option labels are parallel and short.
- The error says what to do: "Choose at least one account".

## Behavior and responsive

- Vertical by default; horizontal wraps on narrow screens.
- "Select all" changes only enabled options.

## Do

- Use a group whenever two or more checkboxes answer one question.

## Don't

- Do not use a group as a single-choice list.
- Do not disable options without saying why in a hint.

## Accessibility

- A `fieldset` with a `legend`, so screen readers announce the question before each option.
- The "select all" checkbox exposes the mixed state (`aria-checked="mixed"`).
- The hint and error are linked to the group with `aria-describedby`.

### Keyboard

| Key | Action |
|---|---|
| Tab | Moves to the next checkbox |
| Space | Checks or unchecks the focused checkbox |

## Example

```tsx
import { CheckboxGroup } from "@leeward/react";

export function StatementAccounts() {
  return (
    <CheckboxGroup
      label="Include these accounts"
      selectAllLabel="All accounts"
      defaultValue={["everyday"]}
      options={[
        { value: "everyday", label: "Everyday" },
        { value: "savings", label: "Rainy day savings" },
        { value: "business", label: "Business", disabled: true, hint: "Statements for business accounts come from Leeward Business" },
      ]}
    />
  );
}
```
