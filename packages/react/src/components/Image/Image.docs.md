# Image

An image that keeps its space while it loads and shows a calm fallback if it fails.

## When to use

- Content images: merchant logos, offer artwork, document previews.

## When not to use

- Icons: use Icon. People: use Avatar.

## Content guidelines

- `alt` says what the image shows, in the context of the page. Use `alt=""` only when the image adds nothing.

## Behavior and responsive

- `ratio` reserves the space, so the page does not jump when the image loads.
- Loads lazily. If it fails, a neutral placeholder takes its place with the same size.

## Do

- Set a ratio for every image in a list.

## Don't

- Do not put text people need inside images.

## Accessibility

- `alt` is required. The fallback keeps the same name, so screen readers still know what was meant.

## Example

```tsx
import { Image } from "@leeward/react";

export function OfferArt() {
  return <Image src="/offers/travel.jpg" alt="Coastline at sunset" ratio="16 / 9" />;
}
```
