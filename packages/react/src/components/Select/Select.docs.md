# Select

Pick one option from a list in a popover. Built on Radix Select.

## When to use

- 5 to 15 options, such as the account to pay from.

## When not to use

- 2 to 5 options that people should compare: use RadioGroup.
- Long lists: use a searchable list.

## Sizes

| Size | Height | Use it for |
|---|---|---|
| `sm` | 36 px (compact 32) | Dense desktop forms. Keeps a 44 px hit area. |
| `md` | 44 px (compact 40) | Default. Same height as a md Button and TextField. |
| `lg` | 48 px (compact 44) | Main choice of a screen. |

## Shapes

| Shape | Corners | Use it for |
|---|---|---|
| `rounded` (default) | The control radius of the size | Forms, dialogs and toolbars. |
| `pill` | Fully rounded ends (`radius-pill` token) and the next size's horizontal padding | Filters in a row of pill Chips or next to a pill Button. |

- A pill is exactly as tall as a rounded control of the same size.
- Match the buttons next to it: pill with pill, rounded with rounded.

## States

- Default, open, hover, focus, error, disabled. Options can be disabled.

## Content guidelines

- Write the placeholder as a request: "Choose an account".
- Keep option labels short and unique. Long values end with an ellipsis instead of wrapping.

## Do

- Order options by how often they are used.

## Don't

- Do not hide important differences between options: use RadioGroup with descriptions.
- Do not use Select for actions: use DropdownMenu.

## Accessibility

- The trigger is a labelled combobox.
- Options are at least 44 px tall.

### Keyboard

| Key | Action |
|---|---|
| Enter, Space or Arrow down | Opens the list |
| Arrow keys | Move between options |
| Enter | Selects |
| Escape | Closes |

## Example

```tsx
import { Select } from "@leeward/react";

export function PayFrom() {
  return (
    <Select
      label="Pay from"
      options={[
        { value: "everyday", label: "Everyday account" },
        { value: "savings", label: "Savings" },
      ]}
      onValueChange={(value) => console.log(value)}
    />
  );
}
```
