# Link

Navigation to another page or site.

## Do

- Use inline links inside sentences: they are always underlined.
- Use external for other sites, so people know a new tab opens.

## Don't

- Do not use a link for actions such as Send or Delete: use Button.
- Do not write "click here". Name the destination.

## Accessibility

- Native anchor. External links add an icon and screen reader text.

## Example

```tsx
<Link href="/fees" variant="standalone">See all fees</Link>
```
