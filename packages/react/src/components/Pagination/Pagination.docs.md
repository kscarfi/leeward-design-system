# Pagination

Moves through a long list, such as a statement, a page at a time.

## When to use

- Desktop tables and lists where people need to reach a specific page.

## When not to use

- Phones and feeds: load more as people scroll, or show a "Show more" button.

## Anatomy

- Previous and next buttons.
- The first and last page, the current page and its neighbours, with "…" for gaps.
- When the total is unknown: "Page 3" between previous and next.

## Behavior and responsive

- `totalPages` known: page numbers are shown. Unknown: pass `hasNext` instead.
- Wraps on narrow screens.

## Do

- Keep the list's sort and filters when the page changes.
- Move focus to the top of the list after a page change.

## Don't

- Do not show more than 7 page buttons.

## Accessibility

- A `nav` named "Pagination"; the current page has `aria-current="page"`.
- Buttons are named "Page 3", "Previous page" and "Next page".
- A polite live region says "Page 3 of 10" after a change.

### Keyboard

| Key | Action |
|---|---|
| Tab | Moves between page buttons |
| Enter or Space | Goes to the page |

## Example

```tsx
import { useState } from "react";
import { Pagination } from "@leeward/react";

export function StatementPages() {
  const [page, setPage] = useState(3);
  return <Pagination page={page} totalPages={12} onPageChange={setPage} />;
}
```
