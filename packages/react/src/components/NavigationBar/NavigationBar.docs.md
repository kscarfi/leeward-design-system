# NavigationBar

Bottom navigation for phones: three to five top-level destinations, each with an icon and a label.

## When to use

- The main sections of a mobile app: Home, Payments, Cards, Profile.

## When not to use

- Desktop: use a side or top navigation.
- Actions such as "Send money": navigation goes to places, it does not do things.

## Anatomy

- An icon and a label per destination.
- The current destination has a filled pill behind a bold icon.
- An optional unread count on the icon.

## Content guidelines

- One word per label: "Home", "Cards".

## Behavior and responsive

- Sits at the bottom of the screen, above the home indicator (safe area).
- Labels truncate rather than wrap.

## Do

- Keep the order the same on every screen.

## Don't

- Do not use more than five destinations or hide labels.

## Accessibility

- A `nav` named "Main"; the current destination has `aria-current="page"`.
- The current state is shown by a pill and a bold icon, not by color alone.
- Counts are read as "3 new" after the label.

## Example

```tsx
import { NavigationBar } from "@leeward/react";

export function AppNavigation() {
  return (
    <NavigationBar
      current="Home"
      items={[
        { label: "Home", icon: "home", href: "/" },
        { label: "Payments", icon: "arrows-left-right", href: "/payments" },
        { label: "Cards", icon: "card", href: "/cards" },
        { label: "Inbox", icon: "inbox", href: "/inbox", count: 2 },
      ]}
    />
  );
}
```
