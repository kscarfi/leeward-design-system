# Breadcrumbs

Shows where a page sits in a hierarchy and links to each level above it.

## When to use

- Desktop screens three or more levels deep, such as Accounts, Everyday, Statements.

## When not to use

- Phones: use PageHeader with a back button.
- Steps in a flow: use Stepper.

## Anatomy

- Links for each level, separated by a chevron.
- The current page last, as plain text.
- A "…" button in place of the middle levels when the path is long.

## Content guidelines

- Use the same names as the pages' titles.

## Behavior and responsive

- Above `maxItems` (default 4), the middle collapses; pressing "…" shows the full path.
- Wraps onto a second line instead of overflowing.

## Do

- Start from the top level the person can reach.

## Don't

- Do not make the current page a link.

## Accessibility

- A `nav` named "Breadcrumb" with an ordered list.
- The current page has `aria-current="page"`.
- Separators are decorative icons, not read aloud.

## Example

```tsx
import { Breadcrumbs } from "@leeward/react";

export function StatementPath() {
  return (
    <Breadcrumbs
      items={[
        { label: "Accounts", href: "/accounts", icon: "home" },
        { label: "Everyday", href: "/accounts/everyday" },
        { label: "Statements" },
      ]}
    />
  );
}
```
