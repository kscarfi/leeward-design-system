# Stack

Lays out children in a column or a row with a gap from the spacing scale, so screens never need hand-written margins.

## When to use

- Any group of elements that needs consistent spacing: a form, a card body, a row of buttons.

## When not to use

- A two-dimensional layout with columns: use CSS grid with the grid tokens.
- Spacing inside a component: components handle their own spacing.

## Behavior and responsive

- `direction="horizontal"` with `wrap` lets a row wrap on narrow screens.
- `gap` takes a spacing token name: `xs` and `sm` inside a group, `md` and `lg` between components, `xl` and up between sections.

## Do

- Nest stacks: a vertical stack of sections, each a stack of fields.

## Don't

- Do not add margins to children of a Stack.

## Tokens

Stack has no tokens of its own: `gap` takes a spacing token name (`--lw-space-<name>`).

## Accessibility

- Renders a `div` by default; use `as` for meaning (`section`, `ul`, `nav`, `form`).

## Example

```tsx
import { Button, Stack, TextField } from "@leeward/react";

export function RecipientForm() {
  return (
    <Stack as="form" gap="lg">
      <Stack gap="md">
        <TextField label="Name" />
        <TextField label="IBAN" numeric />
      </Stack>
      <Stack direction="horizontal" gap="sm" justify="end" wrap>
        <Button variant="ghost">Cancel</Button>
        <Button type="submit">Save recipient</Button>
      </Stack>
    </Stack>
  );
}
```
