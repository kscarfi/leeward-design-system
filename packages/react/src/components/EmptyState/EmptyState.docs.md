# EmptyState

Shown when a list or search has nothing to show yet.

## Do

- Say what is missing, then what people can do.
- Offer one action when there is a clear next step.

## Don't

- Do not blame people for an empty state.

## Accessibility

- Real heading at the level you choose. The illustration is decorative.

## Example

```tsx
<EmptyState icon="wallet-money" title="No payments yet" description="Your payments show up here." />
```
