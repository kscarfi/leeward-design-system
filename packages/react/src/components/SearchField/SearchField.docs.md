# SearchField

A text field for searching, with a search icon and a clear button. Pill by default.

## When to use

- Searching transactions, recipients, help articles.

## When not to use

- Choosing one value from a list: use Combobox.

## Content guidelines

- The label says what is searched: "Search transactions". The placeholder gives an example: "Merchant or amount".

## Behavior and responsive

- The clear button appears once there is text; Escape also clears it.
- Enter calls `onSearch`; results that update while typing only need `onValueChange`.

## Do

- Show the number of results near the list.

## Don't

- Do not use the placeholder as the only label.

## Accessibility

- Wrapped in a `search` landmark.
- The clear button is named "Clear search" and moves focus back to the field.

### Keyboard

| Key | Action |
|---|---|
| Enter | Searches |
| Escape | Clears the text |

## Example

```tsx
import { SearchField } from "@leeward/react";

export function TransactionSearch() {
  return <SearchField label="Search transactions" placeholder="Merchant or amount" onSearch={(q) => console.log(q)} />;
}
```
