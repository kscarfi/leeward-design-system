# SkipLink

A link that lets keyboard and screen reader users jump past the navigation to the main content. Hidden until it gets focus.

## When to use

- On every page with navigation before the main content. Make it the first focusable element.

## When not to use

- Inside components or dialogs.

## Behavior and responsive

- Appears at the top start corner when focused with Tab, and hides again on blur.
- Points to an element with `id="main"` by default; set `targetId` to change it. Give that element `tabIndex={-1}` so focus moves into it.

## Do

- Put it before the logo and navigation.

## Don't

- Do not hide it with `display: none`: it must be focusable.

SkipLink uses the md control radius, the focus ring and the tooltip layer.

## Accessibility

- A normal link, so screen readers list it with the page's links.
- Text defaults to "Skip to main content" or "Ana içeriğe geç".

## Example

```tsx
import { SkipLink } from "@leeward/react";

export function Layout() {
  return (
    <>
      <SkipLink />
      <nav aria-label="Main">...</nav>
      <main id="main" tabIndex={-1}>...</main>
    </>
  );
}
```
