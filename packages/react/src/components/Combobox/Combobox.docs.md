# Combobox

A text field that filters a list as people type, for choosing one value from many, such as a bank.

## When to use

- One choice from more than about 15 options, or options people know by name.

## When not to use

- Fewer than about 15 options: use Select. Free text search: use SearchField.

## Content guidelines

- Options have a short label and an optional second line, such as a bank code.

## Behavior and responsive

- The list opens on focus and filters on label and description, matching Turkish letters correctly.
- Enter or a click chooses an option; clearing the text clears the value.

## Do

- Put the most common options first.

## Don't

- Do not use it for actions.

## Accessibility

- WAI-ARIA combobox with a listbox popup; the active option is announced with `aria-activedescendant`.
- The number of results is read in a status region.

### Keyboard

| Key | Action |
|---|---|
| Arrow down | Opens the list or moves down |
| Arrow up | Moves up |
| Enter | Chooses the active option |
| Escape | Closes the list, then clears the text |

## Example

```tsx
import { Combobox } from "@leeward/react";

export function BankPicker() {
  return (
    <Combobox
      label="Bank"
      placeholder="Start typing a bank name"
      options={[
        { value: "leeward", label: "Leeward" },
        { value: "ziraat", label: "Ziraat Bankası", description: "TR00 0001" },
        { value: "isbank", label: "Türkiye İş Bankası", description: "TR00 0064" },
      ]}
    />
  );
}
```
