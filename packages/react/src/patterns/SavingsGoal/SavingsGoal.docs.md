# SavingsGoal

A savings goal: what people saved, the target, progress and the date they want to reach it.

## When to use

- Savings screens and the home screen, one card per goal.

## When not to use

- Spending limits: use ProgressBar with a warning tone and words.
- Account balances: use AccountCard.

## Anatomy

- Icon and goal name, with the target date under it.
- Saved amount and "of target".
- Progress bar with the percentage, or "Goal reached".
- Optional "Add money" button.

## Content guidelines

- Name goals in the person's words: "Holiday fund", "New laptop".
- Show the date as a full date: "By 1 June 2027".

## Behavior and responsive

- Progress stops at 100%; above the target the bar turns to the success tone and says "Goal reached".
- Percentages round down, so a goal never shows 100% before it is reached.

## Do

- Offer "Add money" on the goal itself.
- Keep amounts in the goal's currency.

## Don't

- Do not color the bar red when people are behind: saving less is not an error.

## Accessibility

- An article named by the goal.
- The progress bar has a visible label ("Progress") and value text, so progress is never shown by color alone. The goal name comes from the article.

## Example

```tsx
import { SavingsGoal } from "@leeward/react";

export function HolidayFund() {
  return (
    <SavingsGoal
      name="Holiday fund"
      saved={18500}
      target={30000}
      currency="TRY"
      locale="tr-TR"
      targetDate={new Date("2027-06-01")}
      onAddMoney={() => {}}
    />
  );
}
```
