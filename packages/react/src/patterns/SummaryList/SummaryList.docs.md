# SummaryList

Label and value pairs that let people check a transfer before they send it, or read a receipt after.

## When to use

- The review step of a transfer or payment: recipient, amount, fee, arrival time, total.
- Receipts and transaction details.

## When not to use

- Lists people choose from: use List and ListItem.
- Long forms: show the fields, not a summary.

## Anatomy

- Rows of label (start) and value (end), separated by subtle lines.
- Optional hint under a value, for example why a fee is zero.
- Optional total row with a stronger line above it.

## Content guidelines

- Labels are short nouns: "Recipient", "Fee", "Arrives".
- Show the fee even when it is zero: "₺0,00", with a hint that says why.
- The total is the exact amount that leaves the account.

## Behavior and responsive

- Values wrap and stay aligned to the end; long IBANs break instead of overflowing.
- Amounts use tabular figures so digits line up.

## Do

- Put the total last and make it the amount people approve.
- Use AmountDisplay for amounts so signs and formatting stay consistent.

## Don't

- Do not hide fees or exchange rates in a hint or tooltip.
- Do not use the summary for editable values: link back to the step instead.

## Accessibility

- A description list (`dl`, `dt`, `dd`), so screen readers announce each label with its value.
- The total row is a normal row with stronger styling, read in order.

## Example

```tsx
import { AmountDisplay, SummaryList } from "@leeward/react";

export function TransferReview() {
  return (
    <SummaryList
      items={[
        { label: "Recipient", value: "Deniz Yılmaz" },
        { label: "Amount", value: <AmountDisplay value={250} currency="TRY" locale="tr-TR" /> },
        { label: "Fee", value: <AmountDisplay value={0} currency="TRY" locale="tr-TR" />, hint: "Free for Leeward accounts" },
        { label: "Arrives", value: "In a few seconds" },
      ]}
      total={{ label: "Total", value: <AmountDisplay value={250} currency="TRY" locale="tr-TR" /> }}
    />
  );
}
```
