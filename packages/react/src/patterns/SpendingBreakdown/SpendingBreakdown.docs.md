# SpendingBreakdown

Spending by category for a period: the total, one bar that shows the shape, and a list with names, amounts and shares.

## When to use

- Monthly spending insights and budget screens.

## When not to use

- Trends over time: use a line chart.
- A single limit: use ProgressBar.

## Anatomy

- Title and total.
- One bar split by category, largest first.
- A row per category: color swatch, optional icon, name, share and amount.

## Content guidelines

- Title names the period: "Spending in November".
- Category names are short and familiar: "Groceries", "Transport".

## Behavior and responsive

- Categories are sorted by amount; zero amounts are left out.
- Shares are rounded to whole percentages; amounts are exact.
- Colors repeat after seven categories; the names and amounts always tell them apart.

## Do

- Keep the list next to the bar: it is the readable version of the chart.
- Limit the list to the main categories and group the rest as "Other".

## Don't

- Do not use red for spending: spending money is not an error.
- Do not show the bar without the list.

## Accessibility

- A section named by its title. The bar is hidden from screen readers; the list carries every value.
- Each row reads name, share ("32% of total") and amount, so color is never the only signal.
- In forced colors mode the bar and swatches get outlines.

## Example

```tsx
import { SpendingBreakdown } from "@leeward/react";

export function NovemberSpending() {
  return (
    <SpendingBreakdown
      title="Spending in November"
      currency="TRY"
      locale="tr-TR"
      categories={[
        { name: "Groceries", amount: 4200, icon: "cart" },
        { name: "Bills", amount: 3100, icon: "bill" },
        { name: "Eating out", amount: 1850, icon: "restaurant" },
        { name: "Transport", amount: 960, icon: "transport" },
      ]}
    />
  );
}
```
