# PaymentCard

Card artwork with the masked number, card name, holder and expiry, and a clear frozen state.

## When to use

- Cards screens, card details and card settings.
- Confirming which card a setting applies to, for example when freezing a card.

## When not to use

- Picking a card from a long list: use ListItem rows with the card name and last four digits.

## Anatomy

- Bank name and card type on top.
- Masked number with the last four digits.
- Card name, holder and expiry at the bottom.
- When frozen: neutral colors and a "Frozen" badge with a lock icon.

## Content guidelines

- Name cards by use: "Everyday debit", "Travel card".
- Expiry is "MM/YY".

## Behavior and responsive

- Keeps the shape of a real card (1.586 to 1) at any width; set the width with its container.
- Only the last four digits are ever passed in, so the full number never reaches the interface.

## Do

- Put card actions (Freeze, Show details) as Buttons next to the card, not on it.
- Show the frozen state on the card itself, so people see it where they look.

## Don't

- Do not pass or show the full card number or the CVV on this component.
- Do not show frozen with color alone: the badge says it in words.

## Accessibility

- An article named in one sentence: card name, "Card ending in 4 8 2 1", expiry and "Frozen" when it is.
- The visual details are hidden from screen readers so they are not read twice.
- Text sits on the primary fill using the color made for it, so contrast passes in every brand and mode.

## Example

```tsx
  return (

    </div>
  );
}
```
