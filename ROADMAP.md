# Roadmap

What is planned, in order. Dates are not promised; the order is.

## Now

- Figma library: a plugin in this repository that builds the Leeward Figma file from the tokens and components (variables with brand and mode, styles, every component and variant, documentation pages and example screens), to be published on Figma Community.

## Next

- Manual accessibility testing with VoiceOver, TalkBack and NVDA, and fixes from it.
- Hosted Storybook.
- Icons as separate modules, so apps only bundle the icons they use.

## Later

- Right-to-left support and review.
- More partner brand tooling: a brand file that designers can edit and export.
- Usage analytics from npm downloads and the MCP server, to decide what to build next.

## Not planned

- Carousel, rating, color picker, tree view and rich text editing: they are rare in banking screens. Open a component proposal if a product needs one.
