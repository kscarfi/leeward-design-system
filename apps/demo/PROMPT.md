# The prompt

This exact text is given to the agent in both runs. Do not change it between runs.

---

Build a money transfer screen for Leeward, a digital bank, as a single React component in TypeScript.

The person should be able to:

1. Choose a recipient from saved recipients, or enter a new name and IBAN.
2. Enter an amount in Turkish lira.
3. Review the transfer: recipient, amount, fee and the total that leaves their account.
4. Confirm with a 6-digit one-time code sent by SMS.

Write the whole screen in one file named `TransferScreen.tsx` with a default export. Use mock data. Make it production quality.

---

Run B adds one line at the end: "Use the Leeward design system. Its MCP server is connected."
